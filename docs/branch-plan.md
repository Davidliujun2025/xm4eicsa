# User Story Branch Plan

## Base Branch

- `develop`: local integration baseline for all feature branches.

## Feature Branches

### `feature/login`

- Scope: login page, session entry flow, auth API contract.
- Touch points: `features/login`.

### `feature/forgot-password`

- Scope: password recovery and reset flow.
- Touch points: `features/forgot-password`.

### `feature/token-quota-management`

- Scope: quota overview, manual adjustment, alert rules.
- Touch points: `features/token-quota-management`.

### `feature/token-usage-view`

- Scope: personal token usage dashboard and detail records.
- Touch points: `features/token-usage-view`.

### `feature/favorite-script-library`

- Scope: script list, favorite/unfavorite, personal favorites.
- Touch points: `features/favorite-script-library`.

### `feature/forbidden-words-management`

- Scope: forbidden word rules and hit logs.
- Touch points: `features/forbidden-words-management`.

### `feature/create-agent-account`

- Scope: agent account creation, role assignment, status management.
- Touch points: `features/create-agent-account`.

### `feature/ai-chat-workbench`

- Scope: conversation layout, message stream, AI assist panel.
- Touch points: `features/ai-chat-workbench`.
